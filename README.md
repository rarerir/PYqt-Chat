1.Чат на pyqt

2.Я хотел создать чат, основанный на базах данных, с интерфейсом на pyqt.

3.В коде существует 2 основных класса: окна регистрации и самого чата.  При открытии программы пользователь вводит свои данные в окно регистрации, и, если она прошла успешно, его переносит на окно чата. В окне чата пользователь может выбрать сервер, в который хочет написать, выйти из аккаунта, обновить чат, написать сообщение или изменить аватар. При отправке сообщения оно сохраняется в бд, а экземпляр сообщения добавляется на табло, это сделано для того, чтобы после каждой отправки сообщения снова не пришлось загружать всю бд с сообщениями. При изменении аватара картинка конвертируется в байткод и после этого отправляется в бд. При парсинге сообщений картинки конвертируются обратно и сохраняются под id соответствующего пользователя, а при выходе они удаляются.
Пользователи подразделяются на обычных и админов. Обычный пользователь может отвечать на сообщения других пользователей, нажимая по ним правой кнопкой мыши и выбирая соответствующую функцию в контекстном меню. Помимо этого пользователь может удалять свои сообщения. Они будут скрыты от всех пользователей, кроме администраторов, для них сообщения будут отображаться под маркой [БЫЛО УДАЛЕНО], при этом администраторы могут удалить сообщения любых пользователей из бд через действие в контекстном меню.

4.В коде я использовал sqlite для работы с бд, pyqt для графического интерфейса, модули sys, os и traceback для дебаггинга ошибок, работы с файлами, а также модуль datetime для определения времени отправки сообщений.
